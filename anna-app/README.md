# RoleFit Studio — Anna AI OS App Package

This directory packages **RoleFit Studio** as a native Schema-4 Anna AI OS App (`@zwhy/rolefit-studio`):

- **`app.json`**: Anna Marketplace listing metadata and `bundled_executas` map.
- **`manifest.json`**: Schema-4 runtime manifest (`desktop` + `mobile` form factors).
- **`bundle/`**: Generated by `npm run build` at the repository root (mobile-safe HTML + static SPA assets + `anna-tool-ids.js`).
- **`executas/rolefit-engine/`**: Zero-dependency Node.js stdio JSON-RPC 2.0 Tool Executa (`analyze_match`, `parse_job_posting`, `audit_bullets`, `export_ats_resume`).
- **`executas/rolefit-coach/`**: Declarative `SKILL.md` for `#rolefit-studio` chat workflows.

## Commands

```bash
# From repo root:
npm run build
anna-app validate --strict --cwd anna-app
anna-app apps push --cwd anna-app
```
